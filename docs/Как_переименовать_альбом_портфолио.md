# Как переименовать альбом портфолио

## Способ 1: Через админку (рекомендуется)

Названия альбомов портфолио берутся из названий услуг (`Service.name`).

**Шаги:**

1. Зайдите в админку: `https://ваш-сайт.ru/{ADMIN_URL}`
2. Перейдите в раздел **"Услуги"** (Services)
3. Найдите нужную услугу (например, "Вывески", "Оклейка авто", "Неон")
4. Нажмите на название услуги для редактирования
5. Измените поле **"Название услуги"** на желаемое
6. Нажмите **"Сохранить"**

**Важно:**
- Изменение названия услуги автоматически изменит название альбома на всех страницах (главная, портфолио, каталог услуг)
- Slug (URL-идентификатор) можно оставить старым, чтобы не ломать ссылки
- Если нужно изменить описание альбома, отредактируйте поле **"Описание"** в той же услуге

## Способ 2: Через код (для разработчиков)

Если нужно захардкодить названия альбомов независимо от услуг, измените файл:

**Файл:** `apps/portfolio/views.py`

**Строки:** 80-87 (метод `get_context_data` класса `PortfolioListView`)

```python
portfolio_albums.append({
    'title': service.name,  # ← Здесь можно захардкодить название
    'slug': service.slug,
    'description': service.description or f'Примеры наших работ в категории "{service.name}"',
    'works': list(works),
    'count': PortfolioItem.objects.filter(is_active=True, service=service).count(),
    'service': service,
})
```

**Пример изменения:**

```python
# Было:
'title': service.name,

# Стало (хардкод для конкретной услуги):
'title': 'Наружная реклама' if service.slug == 'vyveski' else service.name,
```

**Недостатки этого способа:**
- Нужно править код при каждом изменении названия
- Несоответствие между каталогом услуг и портфолио (в каталоге будет старое название)
- При обновлении сайта изменения могут быть перезаписаны

## Какой способ выбрать?

| Критерий | Способ 1 (Админка) | Способ 2 (Код) |
|----------|-------------------|----------------|
| **Удобство** | ⭐⭐⭐ Просто, без кода | ⭐ Требуется разработчик |
| **Гибкость** | ⭐⭐ Меняется везде | ⭐⭐⭐ Можно настроить под конкретные случаи |
| **Поддержка** | ⭐⭐⭐ Легко обновлять | ⭐ Нужно править код при каждом изменении |
| **Консистентность** | ⭐⭐⭐ Единое название везде | ⭐ Может быть рассинхрон |

**Рекомендация:** используйте **Способ 1** через админку для 99% случаев.

## Где отображается название альбома?

1. **Главная страница** — блок "Наши работы" (4 альбома по 4 фото)
2. **Страница портфолио** (`/portfolio/`) — список альбомов (без фильтра)
3. **Фильтры портфолио** — кнопки фильтров по категориям
4. **Каталог услуг** (`/services/`) — карточки услуг

Все эти места используют `Service.name`, поэтому изменение в админке обновит название везде.

---

## Как добавить новый альбом?

1. Создайте новую услугу в админке (раздел "Услуги")
2. Добавьте работы в портфолио и свяжите их с этой услугой (поле "Услуга" при создании работы)
3. Альбом автоматически появится на главной и в портфолио

**Порядок отображения альбомов:**
- Сортируется по полю **"Порядок"** (`Service.order`)
- Чем меньше число, тем выше в списке

## FAQ

**В:** Можно ли скрыть альбом, не удаляя услугу?  
**О:** Да, снимите галочку **"Активна"** в настройках услуги. Альбом исчезнет из портфолио, но услуга останется в базе.

**В:** Почему в портфолио показывается только 4 работы, а их больше?  
**О:** На главной странице и в списке портфолио (без фильтра) показываются первые 4 работы каждой категории. Чтобы увидеть все работы, нажмите кнопку **"Смотреть все работы (X)"**.

**В:** Как изменить порядок работ внутри альбома?  
**О:** В админке (раздел "Портфолио") измените поле **"Порядок"** у нужных работ. Чем меньше число, тем выше в списке. Также можно редактировать порядок прямо в таблице (inline edit).
