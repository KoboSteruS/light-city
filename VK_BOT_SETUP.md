# Уведомления о заявках во ВКонтакте

Заявки с сайта (форма и «Заказать звонок») отправляются **личными сообщениями** от сообщества ВК указанным пользователям.

Telegram-бот **больше не используется** для заявок. Отдельный процесс `telegram_bot` на сервере **не нужен**.

---

## 1. Сообщество ВК

1. Создайте или откройте **сообщество** (группу).
2. Управление → **Работа с API** → создать ключ доступа.
3. Права ключа: **Сообщения сообщества** (обязательно).
4. Скопируйте ключ — это `VK_ACCESS_TOKEN`.

---

## 2. Файл `.env` на сервере

```env
VK_ACCESS_TOKEN=ваш_ключ_сообщества
VK_API_VERSION=5.199
```

Старый `TELEGRAM_BOT_TOKEN` можно удалить или оставить — на заявки не влияет.

---

## 3. Получатели (ID пользователей)

Админка → **Получатели VK (заявки)** → **Добавить**:

| Поле | Значение |
|------|----------|
| VK peer_id | число, обычно `123456789` (user_id). При необходимости может быть отрицательным |
| Имя / подпись | для себя: «Максим» |
| Активен | ✓ |

**Важно:** пользователь должен **разрешить сообщения от сообщества** или **написать сообществу первым** — иначе VK вернёт ошибку 901/902.

---

## 4. Деплой

```bash
cd /var/www/yrkiy_gorod
source venv/bin/activate
git pull
python manage.py migrate
sudo systemctl restart yrkiy_gorod

# Telegram-бот на сервере больше не нужен:
# sudo systemctl stop telegram-bot
# sudo systemctl disable telegram-bot
```

---

## 5. Проверка

1. Отправьте тестовую заявку с сайта.
2. Смотрите логи:

```bash
tail -f logs/yarko_gorod.log | grep -i vk
```

Успех: `Заявка отправлена в VK user_id=...`

---

## Как узнать ID пользователя ВК

- Сервисы вроде vk.com/id… (если есть короткая ссылка).
- Метод API `users.get` по ссылке на профиль.
- Пришлите список ID разработчику — добавим в админку.

---

## Ошибки VK

| Код | Причина |
|-----|---------|
| 901 | Пользователь запретил сообщения от сообщества |
| 902 | Нельзя отправить — нет диалога (напишите сообществу из VK) |
| 5 | Неверный или просроченный токен |
| 15 | Нет права «Сообщения сообщества» у ключа |
